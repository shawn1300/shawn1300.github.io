# 2026-07-26 开发日志

## 本次改进：编辑器体验 + 链接响应速度 + 移动端体验

### 1. 后台编辑器：滚动后看不到侧栏和保存按钮

- `app/(blog)/admin/layout.tsx`：布局改为 `flex-col md:flex-row`，适配移动端
- `components/admin/sidebar.tsx`：
  - 桌面端侧栏改为 `sticky top-14 h-[calc(100vh-3.5rem)]`，长文滚动时侧栏始终可见（自身可滚动）
  - 新增移动端顶部横向导航条（原侧栏在窄屏会挤压内容）
- `components/admin/post-editor.tsx` / `diary-editor.tsx`：顶部操作栏（保存草稿/发布/保存按钮）改为 `sticky top-14`，带半透明背景 + backdrop-blur，写多长都能随时保存

### 2. 链接点击响应慢

原因：所有公开页 `force-dynamic`，每次跳转都现场查 Supabase，且文章列表有 N+1 标签查询（每篇文章两次额外往返）。

- 新增 `lib/supabase/static.ts`：无 cookies 依赖的静态 Supabase 客户端（公开内容只读，不需要 session）
- `lib/posts.ts` / `lib/diaries.ts`：
  - 全部读取函数用 `unstable_cache` 包裹，`revalidate: 60` + 缓存标签 `posts` / `diaries` / `categories`
  - 文章标签改为嵌套 select `post_tags(tag:tags(*))` 一次查完，消除 N+1
- 公开页面移除 `force-dynamic`，改 `export const revalidate = 60`（首页因 searchParams 保持动态，但数据层已走缓存）
- 后台 API（posts/diaries 的创建/更新/删除）保存成功后 `revalidateTag(tag, "max")`，发布后公开页立即更新（Next 16 起 revalidateTag 需要第二个 profile 参数）

### 3. 移动端体验

- `app/layout.tsx`：补充 `viewport` 导出（device-width / initialScale 1 / viewportFit cover）
- `app/globals.css`：
  - `touch-action: manipulation` 消除点击 300ms 延迟；去掉 tap 高亮
  - 移动端输入框最小 16px，避免 iOS 聚焦自动放大
  - `body overflow-x: clip` 防横向滚动
- `components/layout/header.tsx`：移动端菜单项加大触控区域（py-2.5 + active 态反馈）
- `components/posts/post-card.tsx`：封面图加 `loading="lazy" decoding="async"`
- 后台移动端：侧栏变为可横滑的顶部标签导航，编辑器内边距缩小（p-4）

### 验证

- `npm run build` 通过；/archive /categories /diaries 已变为静态 + 1 分钟 ISR
