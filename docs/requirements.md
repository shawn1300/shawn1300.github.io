# 项目需求文档

## 1. 核心功能

### 1.1 首页 / 文章列表
- 极简暗黑风格，展示文章标题、发布日期、分类标签、简短摘要
- 支持分页或无限滚动
- 可按分类筛选

### 1.2 文章详情页
- 完美渲染 Markdown 内容（代码高亮、表格、图片）
- 显示文章元数据：发布日期、分类、标签
- 评论区在文章下方

### 1.3 评论系统
- 读者无需登录即可评论
- 输入项：昵称（默认"匿名"）、邮箱（选填）、评论内容
- 评论实时写入 Supabase 并即时展示（Realtime）
- 按时间正序排列

### 1.4 后台管理（CMS）
- 博主通过 Supabase Auth（email/password）登录
- 文章管理：列表查看、新建、编辑、删除、草稿/发布状态切换
- 分屏 Markdown 编辑器：左侧编辑 + 右侧实时预览
- 图片上传：上传到 Supabase Storage，返回 URL 插入编辑器
- 分类与标签管理

## 2. 非功能需求

- 纯暗黑模式，始终 dark，无切换
- 响应式设计，适配桌面和移动端
- SEO 友好：动态元数据、sitemap、Open Graph
- 性能优先：服务端渲染、增量静态生成
