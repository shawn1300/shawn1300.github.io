# 环境图表提示卡边界修复设计

## 问题

环境监测折线图的提示卡固定显示在数据点上方。当温度或湿度较高、数据点接近图表顶部时，提示卡会越过图表容器，并被容器的裁切规则遮掉一部分。

## 目标

- 提示卡始终完整保留在图表边框内。
- 桌面端鼠标、移动端触控和键盘选择使用相同的定位规则。
- 不改变现有图表尺寸、曲线选择逻辑或提示内容。

## 方案

根据所选数据点在图表中的相对位置选择提示卡方向：

- 靠近顶部时显示在数据点下方，否则显示在上方。
- 靠近右侧时向左展开，否则向右展开。
- 在四种方向上加入固定安全间距，避免提示卡与数据点重叠。

定位只由图表模型中的坐标决定，不额外读取 DOM 尺寸，因此不会引入鼠标移动时的重复布局计算。现有图表容器仍负责裁切超出区域；提示卡本身通过方向翻转留在容器内。

## 验证

- 为定位函数覆盖左上、右上、左下、右下四种位置。
- 运行环境图表单元测试、TypeScript 检查和相关文件 lint。
- 在桌面与窄屏视口分别检查顶部高值、右侧边缘和一般位置的提示卡。
